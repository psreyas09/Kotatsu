# Icon Placeholder

To add an application icon:

1. Place a PNG icon file named `icon.png` in this directory
2. Recommended size: 512x512 pixels
3. The icon will be used for:
   - Application window
   - Desktop shortcuts
   - Package installers (DEB, RPM, AppImage)

For now, the application will use a default icon.

You can use the Kotatsu logo from the Android app's resources:
- Location: ../../../app/src/main/res/mipmap-xxxhdpi/ic_launcher.png
